# Plan 04-01: Multi-Turn Refinement & Local Persistence

## Goal
Implement progressive refinement ("Keep Building Context") for multi-round question drill-downs, hydration-safe LocalStorage session store with LRU pruning, and interactive sidebar session manager.

## Requirements
- REF-01: "Keep Building Context" generates deeper follow-up questions.
- REF-02: Edit existing answers and re-synthesize prompt variants.
- SESS-01: Persist sessions in LocalStorage.
- SESS-02: Sidebar with search, domain filters, new chat button, and delete options.
- SESS-03: Storage quota management and LRU pruning.

## Tasks
1. Create `src/lib/storage.ts` with hydration-safe LocalStorage subscription, schema migration, and LRU pruning.
2. Update `/api/generate-questions/route.ts` to support refinement mode (passing previous prompt and answered questions).
3. Build `src/components/Sidebar.tsx` with session history, search, new chat, and delete actions.
4. Integrate refinement workflow into `src/app/page.tsx` and `src/components/PromptViewer.tsx`.
5. Verify build with `npm run build`.
