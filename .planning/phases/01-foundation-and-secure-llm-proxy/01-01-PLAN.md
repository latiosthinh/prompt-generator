# Plan 01-01: Project Scaffold & Secure LLM Proxy

## Goal
Scaffold Next.js App Router project in `D:\Projects\PromptGenerator`, install Tailwind CSS v4, Lucide React, Zod, and OpenAI SDK, and implement server-side Xiaomi-MiMo client with JSON extraction and schema validation.

## Requirements
- INFRA-01: Next.js App Router project with latest TypeScript, Tailwind CSS, and Lucide React.
- INFRA-02: Server-side route handler proxying Xiaomi-MiMo API (`https://token-plan-sgp.xiaomimimo.com/v1`).
- QUES-05: Robust JSON parser and Zod validator for model completions.

## Tasks

### Task 1: Scaffold Next.js Application & Dependencies
- Initialize Next.js project with App Router, TypeScript, ESLint, Tailwind CSS in current directory.
- Install `openai`, `zod`, `lucide-react`, `clsx`, `tailwind-merge`.
- Configure `tsconfig.json`, `next.config.ts`, `postcss.config.mjs`, and Tailwind setup.

### Task 2: Implement Xiaomi-MiMo LLM Service & JSON Parser
- Create `src/lib/mimo.ts` configuring OpenAI SDK client pointing to `process.env.XIAOMI_MIMO_BASE_URL || 'https://token-plan-sgp.xiaomimimo.com/v1'` and `process.env.XIAOMI_MIMO_API_KEY`.
- Create `src/lib/json-parser.ts` with `extractJsonPayload<T>(text: string, schema: z.ZodType<T>)` to safely strip markdown fences and validate payloads.
- Create `src/types/schemas.ts` defining question, option, and prompt schemas.

### Task 3: Implement API Route Handler & Healthcheck Test
- Create `src/app/api/generate-questions/route.ts` accepting `{ seed: string, domain: string }` and returning validated questions payload.
- Create automated test/verification script `scripts/test-api.ts` or standalone route check to confirm parsing and proxying.

## Verification
- `npm run build` succeeds without TypeScript or bundling errors.
- Unit check verifies `extractJsonPayload` handles raw JSON, markdown-wrapped JSON, and handles syntax errors safely.
