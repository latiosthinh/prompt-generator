## Recommended Stack

| Technology | Version | Purpose | Why |
|------------|---------|---------|-----|
| Next.js (App Router) | `^16.3.3` | Fullstack web framework | Native route handlers for secure API key proxying, SSR/client boundaries, zero-config asset optimization |
| React | `^19.2.8` | UI Library | Concurrent rendering, standard with modern Next.js |
| TypeScript | `^5.8.0` | Type Safety | Enforce strict structured output contracts from LLM to UI |

### OpenAI-Compatible Client & AI Integration
| Technology | Version | Purpose | Why |
|------------|---------|---------|-----|
| `openai` (Official SDK) | `^7.5.0` | Xiaomi-MiMo API Client | Official, robust handling of custom `baseURL` (`https://token-plan-sgp.xiaomimimo.com/v1`), streaming SSE, JSON schema response formatting |
| `zod` | `^4.4.3` | Schema validation | Validates dynamic question structures generated by Xiaomi-MiMo, guarantees type safety on client |

| Technology | Version | Purpose | Why |
|------------|---------|---------|-----|

| Technology | Version | Purpose | Why |

## Architecture & Integration Pattern

### 1. Xiaomi-MiMo Client Setup (Server Route Handler)

Use `openai` SDK with custom `baseURL`:

```typescript
// src/lib/mimo.ts
import OpenAI from 'openai';

export const mimoClient = new OpenAI({
  apiKey: process.env.XIAOMI_MIMO_API_KEY || '',
  baseURL: process.env.XIAOMI_MIMO_BASE_URL || 'https://token-plan-sgp.xiaomimimo.com/v1',
});

export const DEFAULT_MODEL = process.env.XIAOMI_MIMO_MODEL || 'mimo-v1';
```

### 2. Structured Dynamic Questions Pipeline

Xiaomi-MiMo output schema for questions:

```typescript
// src/types/questionnaire.ts
import { z } from 'zod';

export const QuestionOptionSchema = z.object({
  id: z.string(),
  label: z.string(),
  description: z.string().optional(),
});

export const ClarificationQuestionSchema = z.object({
  id: z.string(),
  category: z.string(), // e.g. "Lighting", "Art Style", "Architecture"
  promptLabel: z.string(),
  type: z.enum(['single_select', 'multi_select']),
  options: z.array(QuestionOptionSchema),
  allowCustom: z.boolean().default(true),
});

export const QuestionnaireResponseSchema = z.object({
  domain: z.string(),
  summary: z.string(),
  questions: z.array(ClarificationQuestionSchema),
});
```

## Alternatives Considered

| Category | Recommended | Alternative | Why Not |
|----------|-------------|-------------|---------|
| AI Client | `openai` SDK (`^7.5.0`) | Vercel AI SDK (`ai`) | `openai` client is direct, zero extra abstraction, straightforward custom `baseURL` support for Xiaomi-MiMo |
| AI Client | `openai` SDK | Raw `fetch` | `openai` handles stream parsing, headers, backoff, and error deserialization out of the box |
| Styling | Tailwind CSS v4 | Shadcn UI / Radix primitives | Minimal custom components built directly with Tailwind v4 keep bundle lean and avoid unnecessary component scaffolding |
| Persistence | `localStorage` + Zustand | Supabase / PostgreSQL | Overkill for v1 prompt generator; LocalStorage satisfies zero-friction, local-only requirement |
