# Plan 02-01: Dynamic Clarification & Questionnaire Engine

## Goal
Implement domain selector, seed input interface, dynamic question fetcher, interactive questionnaire form with single/multi choices, persistent "Other" custom text inputs, and "Let AI Decide" fast actions.

## Requirements
- DOM-01: Prompt domain selector (Image Gen, Coding/Tech, Writing, Agent/System Prompts, Custom).
- DOM-02: Seed input box with character counter and sample prompt chips.
- QUES-01: Fetch dynamic clarification questions from `/api/generate-questions`.
- QUES-02: Render single-select and multi-select question cards.
- QUES-03: Editable "Other" custom text input per question that retains input focus and value.
- QUES-04: "Let AI decide" quick selection and skip capabilities.

## Tasks
1. Create domain definitions in `src/config/domains.ts` with labels, icons, example seeds, and placeholder suggestions.
2. Build UI components:
   - `src/components/DomainSelector.tsx`
   - `src/components/SeedInput.tsx`
   - `src/components/QuestionCard.tsx` (supporting single/multi select, custom "Other" text input with autofocus/debounce, and "Let AI Decide" toggle)
   - `src/components/QuestionnaireForm.tsx`
3. Wire components into `src/app/page.tsx` with responsive layout and state handling.
4. Verify with build test.
